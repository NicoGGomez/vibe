# Vibe 🛍️

## 🛠️ Tecnologías

- JavaScript
- Node.js
- Express
- PostgreSQL
- Supabase
- JWT
- Mercado Pago
- HTML
- CSS

- Registro e inicio de sesión
- Autenticación mediante JWT
- Roles de usuario y administrador
- Gestión de productos
- Categorías
- Carrito de compras
- Cálculo de envío
- Checkout
- Integración con Mercado Pago
- Panel de administración

## 🏗️ Arquitectura

Frontend → API REST → PostgreSQL/Supabase
